Sherlock skill

Find a person's accounts across ~450 websites with your AI agent: it turns a short description into username variants, checks them, verifies which profiles are really that person, and writes a clean HTML report.

Install as a skill

Paste this into your agent. It asks whether to install for this project or globally — or to use the standalone guide with nothing installed.

How it works

  • Brief → username variants → bulk check → browser checks → identity verification → report, with a stop for your approval at each key step.
  • Uses Sherlock's live site list as data; the checker is plain Python standard library — nothing to install.
  • Calibrates every site with random usernames to filter false positives.

Use it responsibly

For lawful purposes only: checking your own footprint, due diligence, research with a legitimate reason. The agent declines requests that look like stalking or harassment, and reports only what pages actually show, with sources.
